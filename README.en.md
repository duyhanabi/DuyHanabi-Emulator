# DuyHanabi Emulator

[Tiếng Việt](README.md)

Bring your favorite classic Java games to your Windows PC. Choose a game `.JAR` or `.JAD` file and start playing — no separate Java installation needed.

## What you can do

- **Make the screen yours:** resize it, choose a device style, and enlarge pixel art while keeping it crisp. You can also record GIFs.
- **Keep an eye on things:** check smoothness, CPU/RAM usage, activity status, and saved game data.
- **Play your way:** automate taps at chosen coordinates, record and replay keyboard and mouse actions, and let the app slow down when hidden.
- **Run multiple sessions:** open up to 50 game sessions, arrange them neatly, and sync controls when needed.
- **Manage your games:** browse added games, clear one game's data, or reset all data saved by the emulator.
- **Use it in your language:** the interface starts in Vietnamese, with English available in the app.

## Download

[Download DuyHanabi Emulator for 64-bit Windows](https://github.com/duyhanabi/DuyHanabi-Emulator/releases/latest)

Run the downloaded file to open the app. The first launch may take a little longer; later launches should be quicker.

## Good to know

- Games may behave differently depending on how each one was made.
- Game speed depends on the game and your PC, so not every game will run at the same frame rate.
- The memory refresh option may not reduce RAM usage immediately for every game.
- The app uses MicroEmulator and Java Runtime components. License and attribution details are included with the release.
