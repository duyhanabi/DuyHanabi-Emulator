# DuyHanabi Emulator

[English](README.en.md)

Chơi lại những tựa game Java quen thuộc ngay trên máy tính Windows. Chỉ cần chọn file game `.JAR` hoặc `.JAD` để bắt đầu — không cần cài Java riêng.

## Có gì trong trình giả lập?

- **Màn hình theo ý bạn:** đổi kích thước, chọn kiểu thiết bị và phóng to hình ảnh mà vẫn giữ nét pixel. Có thể ghi lại màn hình thành GIF.
- **Dễ theo dõi:** xem độ mượt, mức dùng CPU/RAM, tình trạng hoạt động và dữ liệu đã lưu của game.
- **Điều khiển thuận tiện:** tự động nhấn theo tọa độ, ghi và phát lại thao tác bàn phím/chuột; ứng dụng tự giảm hoạt động khi bị ẩn.
- **Chạy nhiều phiên:** mở tối đa 50 phiên game, sắp xếp chúng gọn gàng và đồng bộ thao tác khi cần.
- **Quản lý dữ liệu:** xem các game đã thêm, xóa dữ liệu của riêng một game hoặc làm mới toàn bộ dữ liệu do trình giả lập lưu.
- **Tiếng Việt và tiếng Anh:** giao diện tiếng Việt được chọn sẵn; có thể chuyển ngôn ngữ trong ứng dụng.

## Tải về

[Tải DuyHanabi Emulator cho Windows 64-bit](https://github.com/duyhanabi/DuyHanabi-Emulator/releases/latest)

Chạy file vừa tải để mở ứng dụng. Lần đầu có thể mất thêm chút thời gian khởi động; những lần sau sẽ nhanh hơn.

## Một vài lưu ý

- Một số game có thể hoạt động khác nhau; điều này tùy thuộc vào cách từng game được tạo.
- Tốc độ chơi phụ thuộc vào game và máy tính, nên không phải game nào cũng đạt cùng tốc độ khung hình.
- Tùy chọn làm mới bộ nhớ có thể không làm giảm RAM ngay với mọi game.
- Ứng dụng có sử dụng MicroEmulator và Java Runtime; thông tin giấy phép và ghi công đi kèm bản phát hành.
